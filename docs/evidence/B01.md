## Problèmes détectés et corrections

1. Ordre B00 → B02 : corrigé en ajoutant seulement les fondations B01 autour
   de `data/`, après sauvegarde vérifiée, sans déplacer ni réimplémenter B02.
2. Docker indisponible initialement : Docker Desktop démarré pour les essais
   locaux. Les autres projets Docker du poste n'ont pas été arrêtés ou modifiés.
3. Port 8080 refusé par Windows lors du premier démarrage : défaut remplacé par
   18000 et accès réellement vérifié. La cause système précise n'est pas affirmée.
4. Réseau entièrement interne : services sains mais publication hôte absente
   (`invalid IP:0`, connexion refusée). nginx rejoint désormais un bridge d'entrée ;
   API/Grafana restent internes, publication limitée à la boucle locale.
5. Secret Grafana 0600 illisible sous UID 472 Linux : correction dossier 0700 /
   fichier 0644, contenu inchangé ; échec reproduit puis contrôle Linux PASS.
6. Port figé dans le test de fumée : le lanceur interroge maintenant le port
   réellement publié par Compose et refuse toute adresse hors boucle locale.
7. Dépendance transitive minimatch signalée par npm : override ciblé verrouillé,
   audit final à zéro, lint/types/tests/build passés. jsdom et TypeScript choisis
   compatibles avec le Node et l'outillage installés. Une dépréciation transitive
   `whatwg-encoding` reste possible à l'installation ; elle n'est pas un test échoué.
8. Dépréciation du client de test FastAPI : dépendance de test `httpx2` verrouillée ;
   la dernière exécution pytest n'émet plus cet avertissement.

Les essais échoués n'ont pas été renommés PASS : seuls les contrôles effectués
après correction sont déclarés réussis. Les sorties préliminaires locales restent
dans `.local/` ; [B01-local-checks.json](B01-local-checks.json) conserve une passe
antérieure aux dernières corrections, [B01-final-checks.json](B01-final-checks.json)
est la référence finale pour code/lint/tests.
