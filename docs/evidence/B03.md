## Implémentation

- Sept contrats logiques 1.0 couvrent les champs §5, leurs types/unités/nullabilité,
  clés et règles de qualité. Le validateur ne produit pas d'ETL ni de métrique.
- Interface commune `collect()` / `validate_manifest()` / `write_raw()`.
  Le générateur et manifeste B02 sont consommés sans aucune modification.
- `PublicDatasetAdapter` utilise une fixture FOCUS-like artificielle, avec ID
  d'extension local ; aucune certification FOCUS ni validation externe revendiquée.
- `Cur2Adapter`, `OpenCostAdapter`, `AwsInventoryAdapter` ne lisent que des fixtures
  locales. CUR utilise un sous-ensemble de colonnes natives ; OpenCost/inventaire
  sont des projections de contrat, pas des parseurs complets d'API fournisseur.
- RAW conserve les octets et le manifeste source ; sidecars de provenance, hashes,
  UUID et UTC réel. Labels séparés des coûts. Création exclusive, marqueur final,
  recharges sans duplication par objet, nouvelles révisions sans overwrite.
- G02 : champ/méthode/base/devise explicites par profil, USD démo strict, aucune
  conversion FX, aucun arrondi, aucune addition CUR/OpenCost.
- Ruff inclut uniquement le nouveau code data en plus de B01 ; exclusions ciblées
  des sources B02. `.gitattributes` préserve les bytes des fixtures hashées.

Les champs de provenance sont disponibles dans RAW et requis par les contrats
CLEAN ; aucune sortie CLEAN n'est créée avant B04.

   contrôle Decimal ajouté ; test et suite entière passent.

   par les nouveaux tests au même niveau. Déplacement des **seuls tests B03** dans
   un sous-dossier non-package ; 12 tests B02 passent de nouveau avec `python -S`.
   Les fichiers B02 n'ont pas été déplacés ni réécrits.

## Limites et décisions à valider

[ADR-003](../adr/ADR-003-base-de-cout-devise.md) matérialise le repli G02 et conserve
PROPOSED pour le coût réel. [ADR-012](../adr/ADR-012-raw-local-immuable.md) documente
les conventions RAW et les décisions d'évolution. Le choix définitif des sources,
des coûts réels et des connecteurs requiert les gates correspondants.

Les recharges sont idempotentes par contenu/profil/partition. Les différentes
révisions ne doivent pas être additionnées ; leur réconciliation métier reste
B04. Atomicité par objet, pas par bundle. Une interruption peut laisser un dossier
incomplet refusé au prochain appel. Les chemins de reçus sont absolus au stockage
local initial ; pas de portabilité entre machines revendiquée. Limites de charge :
64 MiB/fichier et 100 entrées/manifeste. Stockage local de confiance, pas de WORM
administré ni de protection contre un attaquant réécrivant tous les hashes.

Les consultations de documentation fournisseur ont servi à vérifier les champs ;
aucun appel d'API AWS, service facturable ou téléchargement de dataset tiers.
CloudFormation reste l'IaC autorisée ; aucune IaC ajoutée et aucun Terraform.
